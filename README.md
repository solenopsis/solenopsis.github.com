# Solenopsis website

The Solenopsis project site is built with [Astro](https://astro.build/) and deployed to GitHub Pages at https://solenopsis.org/.

## Development

```bash
npm install
npm run dev
```

Build the static site with:

```bash
npm run build
```

The generated site is written to `dist/` and deployed by GitHub Actions.

## Projects

The site currently highlights the surviving Solenopsis repositories:

- [Solenopsis](https://github.com/solenopsis/Solenopsis)
- [SOAP](https://github.com/solenopsis/soap)
- [Session](https://github.com/solenopsis/session)
- [Metadata](https://github.com/solenopsis/metadata)
- [SLoggly](https://github.com/solenopsis/sloggly)

The archived Lasius repository is intentionally not presented on the public site.
